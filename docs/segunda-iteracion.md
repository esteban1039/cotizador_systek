# Iteración 2: editor móvil

## Entregado

- Interfaz Nuxt en español, adaptable a escritorio y móvil.
- Cliente/sede, catálogo vigente, cantidades, descuentos, alcance y condiciones.
- Vista previa de totales desde Laravel, con cancelación de respuestas antiguas.
- Guardado explícito y pantalla de detalle; listado paginado de borradores.
- Nombres del cliente y sede guardados dentro de cada nueva copia.
- Validación de origen del proxy y token exclusivo del servidor.
- Arranque Docker corregido para que Laravel conserve la configuración PostgreSQL al atender HTTP.

## Límites

Todavía es un entorno de desarrollo local. Sin gestión de clientes, modificación de borradores existentes, autenticación individual, PWA instalable, IA, PDF ni aprobación/emisión. Los precios de ejemplo y las condiciones de la demostración no constituyen reglas comerciales autorizadas.

## Próximo paso

Usuarios y permisos individuales, administración de clientes/sedes/contactos y catálogo. Después: reglas de aprobación, versiones comerciales y PDF. El editor actual sirve para validar el flujo CCTV con Systek.
